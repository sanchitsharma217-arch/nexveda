## ✨ Key Features & Capabilities

- 🚀 **100/100 Core Web Vitals**: Engineered for zero-cls layout shifts, sub-second LCP, and ultra-low input latency.
- 💎 **Glassmorphism & Aurora UI System**: Next-generation obsidian dark mode, vibrant cyan accents, and dynamic backdrop filters.
- 🎯 **Interactive 3D Spotlight & Custom Cursor**: Physics-driven hover states, cursor morphing, and spotlight glow effects.
- 🌀 **Lenis & GSAP Motion Engine**: Ultra-smooth 60 FPS scroll-triggered micro-animations and interactive parallax transforms.
- 📊 **Interactive Cost Estimator & Calculator**: Real-time project scope pricing estimator for enterprise clients.
- ⚖️ **Architecture Comparison Matrix**: Side-by-side technical breakdown vs standard agencies and off-the-shelf templates.
- 💼 **Case Study & Project Portfolio Engine**: Detailed project showcases with interactive modals and key metrics.

## 🚀 Quick Start & Local Setup

To run Nexveda locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/sanchitsharma217-arch/nexveda.git

# 2. Navigate to the project directory
cd nexveda

# 3. Start local development server
npm run dev
```

Open your browser and navigate to `http://localhost:3000`.
